## TIPS FOR BEST RESULTS

1. **Use the same art style suffix on every prompt** — this keeps everything visually consistent
2. **Generate in batches** — do all characters first, then equipment, then UI
3. **Transparent backgrounds** — always specify "transparent background" so PNGs have no backdrop
4. **If using Midjourney** — add `--no background --style raw` to each prompt
5. **If using DALL-E** — it doesn't support transparent backgrounds natively, so use a solid green screen color and remove it with remove.bg after
6. **Resolution** — generate at 2x the listed size, then downscale for crispness
7. **Check each image** — if a sprite looks wrong, regenerate it. AI is inconsistent.
